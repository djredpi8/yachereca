# Assets

Положите изображения в эту папку со следующими именами:

- `image1.jpg` — отправляется после `/start`
- `image2.jpg` — после 1-го нажатия кнопки
- `image3.jpg` — после 2-го нажатия кнопки
- `image4.jpg` — после 3-го нажатия кнопки
- `image5.jpg` — после 4-го нажатия кнопки

Если файл отсутствует, бот отправит текстовый маркер о пропущенном файле.
