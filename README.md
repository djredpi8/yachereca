# yachereca

Telegram-бот на `aiogram` с циклом из 5 нажатий одной кнопки.

## Логика цикла

После `/start` бот показывает кнопку с первым текстом. На каждом нажатии текст кнопки меняется, чтобы следующее сообщение отправлялось **от пользователя** в нужной последовательности:

1. `Я хочу ящерицу!` — бот не отвечает.
2. `Ящерица!` — бот отвечает:
   - `Ящерица!`
   - `{user_name}, может все таки хомячка?`
3. `Ящерицу!` — бот не отвечает.
4. `Ящерица` — бот не отвечает.
5. `Ящерица` — бот отвечает:
   - `Ящерица`
   - `{user_name}, ты дурак совсем?`
   - и сбрасывает цикл к шагу 1.

## Быстрый старт

1. Установите зависимости:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. Создайте токен в BotFather и задайте переменную окружения:

```bash
export BOT_TOKEN="<ваш_токен>"
```

3. Запустите бота:

```bash
python bot.py
```

## Важно по безопасности

- Не храните токен в коде.
- Если токен уже попал в публичный доступ, обязательно отзовите его через BotFather (`/revoke`) и выпустите новый.
