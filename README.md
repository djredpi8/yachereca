# yachereca

Telegram-бот на `aiogram` с двумя постоянными кнопками **«Ящерица»** и **«Сначала»**, сценарием по нажатиям и отправкой изображений.

## Логика

После `/start`:
1. Бот отправляет **картинку 1**.
2. Бот пишет: `Ты можешь выбрать любого питомца, которого ты захочешь`.
3. Показывает кнопки `Ящерица` и `Сначала`.
4. Кнопка `Сначала` в любой момент запускает сценарий заново (аналог `/start`).

Дальше считаются нажатия на кнопку:

1. Нажатие №1:
   - сценарная реплика пользователя: `Я хочу ящерицу!`
   - бот отвечает: `Нуу не знаю, что тебе нравится`
   - бот отправляет **картинку 2**

2. Нажатие №2:
   - сценарная реплика пользователя: `Ящерица!`
   - бот не отвечает текстом
   - бот отправляет **картинку 3**

3. Нажатие №3:
   - сценарная реплика пользователя: `Ящерицу!`
   - бот не отвечает текстом
   - бот отправляет **картинку 4**

4. Нажатие №4:
   - сценарная реплика пользователя: `Ящерица`
   - бот отвечает: `{user_name}, ты дурак совсем?`
   - бот отправляет **картинку 5**
   - и сбрасывает счётчик в новый цикл

> Технически Telegram отправляет текст кнопки (`Ящерица`). Сценарные реплики трактуются как шаги по номеру нажатия.

## Куда положить картинки

Папка: `assets/`

Нужные файлы:
- `assets/image1.jpg`
- `assets/image2.jpg`
- `assets/image3.jpg`
- `assets/image4.jpg`
- `assets/image5.jpg`

## Быстрый старт

1. Установите зависимости:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. Создайте токен в BotFather и задайте переменную окружения:

```bash
export BOT_TOKEN="<ваш_токен>"
```

3. Запустите бота:

```bash
python bot.py
```

## Важно по безопасности

- Не храните токен в коде.
- Если токен уже попал в публичный доступ, обязательно отзовите его через BotFather (`/revoke`) и выпустите новый.
